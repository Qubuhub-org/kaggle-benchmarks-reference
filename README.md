# Overview

This repository provides infrastructure and reference materials for executing and evaluating agentic tasks. It contains three primary components:

* **Dockerfiles:** Container configurations to build isolated images for running agent environments and workflows.
* **Starter Templates:** Boilerplate code and project structures for getting started with agent development.
* **Benchmark Reference Implementations:** Implementations of major agentic benchmarks—including OSWorld and The Agent Company—adapted specifically for execution on Kaggle.
